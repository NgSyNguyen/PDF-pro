# License texts

The full texts of the licenses of what PDF_Pro ships, as their authors publish them; `THIRD_PARTY_NOTICES.md` (next to
this folder) says which component is under which license.

| File | Covers |
|---|---|
| `Apache-2.0.txt` | Apache License 2.0: Serilog and its sinks, PDFiumCore, the PDFium binaries' packaging, PdfPig, qpdf, Tesseract and its trained data |
| `CommunityToolkit.Mvvm.txt` | MIT, as published by the .NET Community Toolkit |
| `WPF-UI.txt`, `WPF-UI-ThirdPartyNotices.txt` | MIT, as published by WPF-UI, and the notices it carries |
| `gong-wpf-dragdrop.txt` | BSD-3-Clause, as published by gong-wpf-dragdrop |
| `SkiaSharp.txt` | MIT, as published by SkiaSharp |
| `OFL-*.txt` | SIL Open Font License 1.1 of each bundled font, with its copyright line |

6.2.4, Tabula, Velopack, System.Security.Cryptography.Pkcs) use the standard MIT text below with the copyright line
their packages state; PDFium (BSD-3-Clause) and the libraries inside it are listed with their licenses in
